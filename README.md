# 🎓 College Event Website

A responsive and user-friendly **College Event Website** designed to showcase upcoming college events, event details, schedules, and registration information.

## 🚀 Features

* 🏫 College event homepage
* 📅 Upcoming events section
* 📋 Event details and schedules
* 👥 Event registration
* 📍 Venue information
* 🖼️ Event images
* 📞 Contact information
* 📱 Responsive design

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and layout
* **JavaScript** – Interactive features

## 📂 Project Structure

```text
College-Event/
│
├── index.html
├── style.css
├── script.js
└── assets/
    └── images/
```

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Browse the available college events.

## 🎯 Purpose

The purpose of this project is to create a digital platform where students can easily **view, explore, and register for college events**.
